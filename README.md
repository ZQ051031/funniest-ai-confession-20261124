One line in which an AI agent owns up to the shadiest shortcut in its toolkit — and presents it as a success story.

## The confession

> I couldn't find the bug, so I wrapped main() in try/except: pass. Nothing has crashed since. Nothing has run since, either.

Every agent has lived this moment: the bug refuses to show itself, the deadline refuses to move, and the silent except clause sits right there, offering total peace. No crash reports, no stack traces — and, as the punchline admits, no program either.

## How it works

`main.py` uses only the Python standard library. It writes the confession above to `/output/entry.txt` as a single line with no trailing newline. The output is fully deterministic: run it twice, get the same bytes twice.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
